# DRMC IT CLUB // 9TH DRMC INTERNATIONAL TECH CARNIVAL
Official Exhibition Voting Matrix & Neural Ballot System

## Quick Start
1. Extract this zip file.
2. Double-click `index.html` to open it in Chrome, Edge, Safari, or Firefox.
3. Everything is fully functional (Firebase Realtime Database connected to `ditc-dad`).

## Features Included in This Release:
- **Branding**: DRMC IT CLUB & 9th DRMC International Tech Carnival.
- **Search**: Search by artist first/last name, piece tag number (e.g. 03, #03), or artwork title, with cross-hall match detection.
- **Artwork Scaling**: Uncropped, proportional view in the Zoom Modal (`object-fit: contain; max-height: 65vh;`) plus a "View Full Resolution" button.
- **Organizer Dashboard**:
  - Hidden access via the tiny decorative dot at the bottom center of the lock screen (or [ORGANIZER PORTAL] in footer) -> enter passcode `nexus2026`.
  - **Tab 1: Live Vote Telemetry** (real-time ballot counts, bar charts, leaderboards, CSV export).
  - **Tab 2: Manage Exhibits & Uploads** (add new cards, quick image upload directly from device, edit details, delete cards, automatic cloud sync to Firebase).
