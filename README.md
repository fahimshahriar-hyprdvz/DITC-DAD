# DRMC IT CLUB // 9TH DRMC INTERNATIONAL TECH CARNIVAL
Official Exhibition Voting Matrix & Neural Ballot System

## Quick Start
1. Place this project inside your GitHub repository root.
2. Store your exhibition images directly in an `exhibits/` folder matching the Exhibit IDs:
   - `exhibits/DA-01.jpg`
   - `exhibits/DA-02.jpg`
   - `exhibits/MP-01.jpg`
   - `exhibits/CS-01.jpg`
   - `exhibits/PD-01.jpg`
3. If an image is missing or not yet added, the portal automatically displays a sleek cyberpunk SVG placeholder and never breaks the layout.
4. The Organizer Portal (`nexus2026`) manages all text metadata (title, artist, category, room tag number, description, tags) and syncs lightweight JSON to Firebase Realtime Database.
